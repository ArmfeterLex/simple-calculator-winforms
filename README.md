# Simple Calculator WinForms

Простой калькулятор на C# Windows Forms с отдельными кнопками для каждой операции.

## Функциональность

- Ввод двух чисел
- Отдельные кнопки для каждой операции:
  - button1 — сложение (+)
  - button2 — вычитание (−)
  - button3 — деление (÷)
  - button4 — умножение (×)
- Вывод результата в текстовое поле
- Кнопка закрытия программы

## Интерфейс

- textBox1 — первое число
- textBox2 — второе число
- textBox3 — результат
- button1 — сложить
- button2 — вычесть
- button3 — разделить
- button4 — умножить
- button5 — выход

## Пример работы

**Сложение:** 5 + 3 = 8
**Вычитание:** 10 - 4 = 6
**Умножение:** 6 × 7 = 42
**Деление:** 15 / 3 = 5

## Куда можно встроить

- В образовательные проекты
- В инженерные приложения
- В системы автоматизации расчётов
- В демонстрацию работы с формами

## Требования

- Windows
- .NET Framework / .NET Core с WinForms

## Примечание

При делении на ноль программа вызовет исключение — для production рекомендуется добавить проверку.
